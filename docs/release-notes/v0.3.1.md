新功能：**查看终端的输出历史**。

- 电脑界面窗口选项卡右侧新增“输出历史”，手机终端页顶部新增“历史”：显示当前面板之前的输出，可以选中或一键复制，最多最近 5 万行。
- tmux 每个面板保留的历史从 1 万行提高到 5 万行（对之后新建的面板生效；已在运行的面板沿用原来的上限）。
- 电脑上也可以在终端里滚动鼠标滚轮往上翻（进入 tmux 的复制模式，按 q 退出）。
- vim、less、top 这类全屏程序的画面不会进入历史。

说明：输出历史保存在 tmux 里，tmux 会话关闭或电脑重启后就没有了。需要长期保留时，可以在“设置 → 保存策略”里打开“保存终端滚动缓冲区”，保存快照时会把输出一起存进你的 Git 仓库（保存前会过滤 Token、密码和私钥）。

这是第一个可以从 0.3.0 自动升级的版本。
