新功能：**自动升级**、**会话选项卡与分组**，并修复手机配对时的 401 错误。

## 自动升级

- 桌面版和命令行版都会在启动后、之后每 6 小时检查一次新版本（“设置 → 通用”可关闭）。有新版本时状态栏会提示，“设置 → 关于”里可以查看更新说明、下载安装。
- 桌面版下载后替换整个应用，点“立即重启”进入新版本；tmux 会话在独立的 tmux 服务里，升级和重启都不会中断它们。
- 命令行版：`tmuxide update` 下载并替换当前程序，`tmuxide update --check` 只检查。正在运行的 `tmuxide serve` 重新启动后使用新版本。
- 升级目录和安装包都用发布私钥签名，程序只认内置公钥：签名不对、版本比已知的旧、压缩包大小或 SHA-256 与签名目录不一致时一律拒绝。
- 先走 GH-Proxy 加速下载，失败再回到 github.com 官方地址；加速只负责传输，内容仍以签名为准。
- 某个版本被标为必须升级时，界面会弹出无法关闭的提示；电脑断网时沿用上次验证过的目录。
- Linux 桌面版只有 AppImage 和 deb 安装方式能自动升级（deb 会请求管理员权限）。

**从 0.2.0 及更早版本升级需要手动安装一次**：旧版本里没有升级功能，请下载本页的安装包覆盖安装。之后的版本就可以自动升级了。

## 会话选项卡与分组

- 工作区顶部新增会话选项卡，点一下就能切换；切走的终端保持连接，切回来立即可用。
- 会话可以分组：在左侧会话树里点会话的“设置分组”，选择已有分组或输入新名称。会话树按分组折叠显示，选项卡上方可以按分组筛选。分组保存在 tmux 会话里，改名后仍然保留。
- 远程管理（另一台电脑上的完整界面）同样可用。手机页面的会话列表按分组排列，终端页面顶部也可以直接切换会话。

## 修复与改进

- 修复：Cloudflare 快速隧道填写了“允许的邮箱”后，手机配对时报 HTTP 401。原因是 Cloudflare 的邮箱验证会话过期后，提交请求被直接拒绝；现在页面会自动重新走一次邮箱验证，并保留已输入的配对码。
- 修复：在电脑浏览器里打开远程页面并使用“保持电脑尺寸”时，终端最下面的输入行被按键栏挡住。现在会按可用的宽度和高度选择字号，放不下时自动滚到光标所在行。
- 远程设置里的访问地址、配对码和配对链接旁边都加了“复制”按钮。

## 更正

0.2.0 的发布说明中写安装包“大约增加 40 MB”，实际增加约 15 MB（内置 cloudflared）。

## 验证情况

- 自动化测试：Rust 单元与集成测试（含真实 tmux）、前端类型检查；浏览器端到端测试覆盖配对、PIN、终端、远程管理、会话选项卡与分组、复制按钮，以及电脑浏览器宽窄两种窗口下光标行可见。
- 升级：用测试密钥在本机验证了命令行版的完整升级（检查 → 下载 → 校验 → 替换），以及篡改目录、篡改安装包时被拒绝；桌面版在本机生成并签名了 deb 和 AppImage 升级包。桌面版的应用内下载、安装和重启没有在真实 macOS / Linux 桌面上测试，第一次自动升级会发生在下一个版本。
