新功能：**用手机远程查看和控制电脑上的终端**。

在电脑上打开“设置 → 远程访问”，选好网络方式、设一个 PIN，打开开关，再点“配对新设备”用手机相机扫码即可。手机上能看到所有正在运行的会话和窗口（实时更新），点开就是真实终端，可以直接输入命令、按 Ctrl-C、切换窗口。

## 网络方式

| 方式 | 需要什么 | 说明 |
| --- | --- | --- |
| Cloudflare 快速隧道 | 什么都不需要 | 已内置 cloudflared 2026.10.0；地址形如 `https://xxx.trycloudflare.com`，每次开启会变 |
| Cloudflare 自有域名 | Cloudflare 账号里的 Tunnel Token | 地址固定，可叠加 Cloudflare Access |
| Tailscale | 电脑和手机都装好并登录 Tailscale | 只在你的 tailnet 内可见，走 HTTPS（tailscale serve），也可直连 tailnet IP |
| 本机端口 | 自己的 frp / ngrok / nginx | 只监听 127.0.0.1 |

## 认证与安全

- 默认关闭。只有在电脑上配对过的设备才能连接：配对码 8 位、5 分钟有效、只能用一次，输错 5 次作废。
- 每台设备获得独立凭证（保存在手机浏览器的 HttpOnly Cookie 中，电脑上只保存其哈希），默认 30 天有效。
- 可要求每次打开时输入 PIN；空闲 30 分钟自动锁定；PIN 连续输错 5 次锁定该设备，需在电脑上解除。
- 设备可以改为只读、断开当前连接或随时移除，立即生效。
- 远程端口只提供终端，不能修改设置、Git 仓库或快照；检查请求来源和域名，防止跨站请求。
- 所有配对、解锁、打开终端、失败尝试都有访问记录；有新设备连接时电脑上会弹出提醒，状态栏显示正在远程打开的终端数。
- Cloudflare 快速隧道可额外填写允许的邮箱，访问前先通过 Cloudflare 的邮箱验证码。

## 手机上

- “保持电脑尺寸”（默认，不改变电脑上的窗口大小，可横向滚动）和“适配手机尺寸”两种显示方式。
- 常用按键栏：Esc、Tab、Ctrl、方向键，以及中断、^D、清屏。
- 可以“添加到主屏幕”像 App 一样打开。

## 其他

- macOS 上远程访问开启期间会阻止电脑空闲睡眠（可关闭）；合上盖子仍会睡眠，电脑睡眠或 TmuxIDE 退出后手机无法连接。
- 命令行版：`tmuxide serve --pair` 在终端里显示配对二维码；`tmuxide info` 显示内置 cloudflared 版本。
