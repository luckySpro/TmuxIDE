修复：

- **终端图标显示成方框**：内置 Nerd Font 图标字体。oh-my-zsh、powerlevel10k、starship 等主题的箭头、Git 分支和文件夹图标，现在不用在电脑上另装字体也能正常显示（电脑界面和手机都是）。
- **macOS 升级时提示“Read-only file system”**：从“下载”文件夹或 DMG 里直接打开 TmuxIDE 时，macOS 会把它放在只读的临时位置运行，无法替换。现在会直接说明原因和处理办法：退出 TmuxIDE，把它拖到“应用程序”文件夹，在终端执行一次 `xattr -dr com.apple.quarantine /Applications/TmuxIDE.app`，再重新打开即可自动升级。
- 检查和下载升级时，如果网络里有公司代理或安全软件替换了证书，会改用系统信任的证书再试一次。
