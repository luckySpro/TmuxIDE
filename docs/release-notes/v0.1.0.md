TmuxIDE 第一个版本：图形化管理 tmux 会话，保存、恢复，并同步到你自己的 Git 仓库。

**一次安装，不需要再装任何依赖**：tmux 3.5a 与 Git 引擎（libgit2 + libssh2 + OpenSSL）都已编进程序，前端资源离线内嵌。

## 下载哪个

| 系统 | 桌面版 | 命令行 + 浏览器界面 |
| --- | --- | --- |
| macOS Apple Silicon（M 系列） | `TmuxIDE_0.1.0_aarch64.dmg` | `tmuxide-0.1.0-macos-arm64.tar.gz` |
| macOS Intel | `TmuxIDE_0.1.0_x64.dmg` | `tmuxide-0.1.0-macos-x86_64.tar.gz` |
| Linux x86_64 | `.deb` / `.AppImage` | `tmuxide-0.1.0-linux-x86_64.tar.gz`（完全静态） |
| Linux arm64 | — | `tmuxide-0.1.0-linux-aarch64.tar.gz`（完全静态） |

不提供 Windows 版：tmux 无法在 Windows 上原生运行。

## 功能

- 会话树（运行中 / 已保存 / 模板）、内嵌 tmux 终端、窗口标签、检查器、⌘K 命令面板
- 保存快照（布局、目录、运行中的命令），内容不变不产生提交；定时自动保存
- 按任意历史版本恢复；同名会话可恢复为新会话 / 替换 / 跳过；会话模板
- Git 同步：SSH 密钥、ssh-agent、HTTPS Token；每台电脑独立目录，多机不冲突；历史与逐行对比
- 可选保存终端输出，保存前过滤 Token、密码、私钥
- 简体中文 / English

## 注意

- macOS 安装包尚未签名：首次打开请在“访达”中右键 TmuxIDE → 打开，或执行 `xattr -dr com.apple.quarantine /Applications/TmuxIDE.app`。
- Linux 桌面版使用系统 WebKitGTK 4.1（主流桌面发行版自带）；服务器请用命令行版 `tmuxide serve`。
- TmuxIDE 使用专用 tmux socket（`tmuxide`），不影响你自己的 tmux 会话。
